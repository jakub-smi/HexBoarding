# ⬣ HEXBOARDING

### Turn onboarding into an experience.

**HexBoarding** is a gamified onboarding and screening tool designed to make user assessment more engaging.

Instead of simply filling out forms and answering a list of questions, users progress through an interactive map — completing challenges, claiming regions, and working their way through a campaign.

**You create the campaign. They conquer it.**

---

## 🗺️ MORE THAN A QUESTIONNAIRE

Traditional onboarding and screening can feel repetitive.

HexBoarding turns the process into something interactive.

Create a campaign, define what you want to test, and let users progress through an interactive map while answering questions along the way.

Every hex becomes another step toward completing the campaign.

---

## ⚔️ HOW IT WORKS

### 1. Create a campaign

Define the topic, questions, and structure of your campaign.

### 2. Give it to a user

The user starts the campaign and enters the interactive map.

### 3. Answer & progress

Questions become part of the progression system.

### 4. Conquer the map

Successful answers allow the user to claim new territory and continue progressing.

### 5. Evaluate the result

Use the completed campaign as a way to assess the user's performance.
